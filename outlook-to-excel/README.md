# Outlook to Excel Automation

A Python script that extracts data from HTML email reports in a folder and automatically updates an Excel workbook. This is the most complex automation project I've built so far.

## What it does

- Reads the latest `.eml` file
- Extracts report tables from the email body
- Calculates BSW values
- Performs combined-field calculations
- Appends results to the next available row in Excel
- Preserves existing workbook formatting

## Tools

- Python
- Pandas
- OpenPyXL

## Notes

This repository contains an anonymized version of the original automation project.

Specific names, file paths, workbook names, report names, and data have been removed or replaced, while the core logic has been preserved for demonstration purposes.

The production workbook and email files are not included.
